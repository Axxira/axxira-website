# DungeonMapPilot — activer les cartes / activate Maps

## Français

Cet outil Windows active uniquement DungeonMapPilot. Offre distincte du leveling :
5,99 $ CA/mois, renouvellement automatique. Consultez le portail pour souscrire.
L'édition de test RaidPilot est gratuite, sans cet outil ni abonnement.

Activation :
1. Installez l'addon DungeonMapPilot, puis fermez complètement WoW.
2. Ouvrez le portail depuis le compagnon. Conservez votre clé personnelle.
3. Confirmez l'abonnement sur PayPal, puis importez la clé dans le compagnon.
4. Choisissez le dossier WoW _forever_ et cliquez Activer / actualiser mon accès.
5. Relancez via Battle.net. Activez DungeonMapPilot et DungeonMapPilot_Access.
6. Tapez /dmp pour afficher les cartes. Langue propose français ou anglais.

Gardez votre clé privée : elle permet de retrouver votre abonnement. Le compagnon
la conserve chiffrée pour votre compte Windows. Actualisez l'accès au moins tous
les sept jours et après un renouvellement; il ne dépasse jamais la période payée.
Annulez les prochains paiements dans le portail. L'annulation conserve la période
payée; un remboursement est pris en compte à l'actualisation suivante.

Les plans de référence ne proposent pas de GPS. La position dépend des cartes
natives et des coordonnées fournies par WoW. La couverture Forever reste en
vérification. Ding, leveling, Farm et bridge sont préservés. Un paiement fictif
ne débloque jamais l'addon public.

## English

This Windows companion activates DungeonMapPilot only. Maps is separate from
ForeverPilot leveling: CAD 5.99/month, renewing automatically. Subscriptions are available through the portal when checkout is enabled. The free RaidPilot testing edition needs neither this tool nor a subscription.

When sales open, install the addon and close WoW. Open the portal, save your
personal key, confirm the subscription on PayPal, import the key here and select
the _forever_ folder. Activate access, restart through Battle.net and enable
DungeonMapPilot plus DungeonMapPilot_Access. Use /dmp and choose your language.

Keep your key private. It is encrypted for your Windows account. Refresh at least
every seven days and after renewal. Cancellation preserves paid time; refunds
take effect on the next refresh. Reference plans have no GPS. Player position
depends on native maps and data supplied by WoW; Forever coverage is still being
verified. Other addons remain untouched. Sandbox tokens never unlock live access.
