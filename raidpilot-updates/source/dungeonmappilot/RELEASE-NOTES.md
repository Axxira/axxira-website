## 0.5.5 - Pro subscription entry point

- Added a dedicated localized Pro / Guides & Tips action directly below the current floor selector (e.g., Graveyard).
- Selecting Pro opens the official DungeonMapPilot account panel and highlights its URL in WoW. The Windows launcher has a browser-opening action for the official website.
- Premium remains optional in the RaidPilot test edition; this update does not remove free maps or restart a route.
- Uses exactly the same DungeonMapPilot directory and SavedVariables names; no duplicate addon.
- The launcher and addon changes have simulated tests; physical in-game confirmation is still required.
