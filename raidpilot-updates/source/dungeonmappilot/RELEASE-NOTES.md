# DungeonMapPilot 0.4.2-alpha — Beta

## Français

Annuler jusqu’à 20 opérations de parcours. Prérequis inconnus ou incomplets bloqués proprement. Bouton rond de minicarte et intégration facultative à PilotCenter.

Bêta pour WoW Forever 1.60.1 uniquement. Fermez complètement WoW puis relancez-le après la mise à jour. Les réglages sauvegardés sont conservés. Les nouveaux comportements et interfaces sont testés avec API simulées; leur rendu et performance en jeu restent à valider. Pas de parcours 1–60 complet ni de gain XP/h garanti. PilotCenter reste facultatif. Les suffixes internes -alpha conservés identifient le paquet local testé; le canal de publication est Beta.

## English

Undo up to 20 route operations. Unknown or incomplete prerequisites fail safely. Round minimap launcher and optional PilotCenter integration.

Beta for WoW Forever 1.60.1 only. Fully exit and restart WoW after updating. Saved settings are preserved. New behavior and UI are tested with simulated APIs; in-game rendering and performance still need validation. No complete 1–60 run or guaranteed XP/hour gain is claimed. PilotCenter is optional. Retained internal -alpha suffixes identify the tested local package; the publication channel is Beta.

Public subscription terms unchanged: CAD 5.99/month. RaidPilot testing edition remains entirely free. / Abonnement public inchangé : 5.99 CAD/mois; édition de test RaidPilot toujours gratuite.
