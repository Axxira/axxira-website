RAIDPILOT LAUNCHER 0.2.8
=========================

CORRECTIF MOTEUR DE SELF-UPDATE 0.2.8
- Corrige la fermeture sans redémarrage observée chez certains utilisateurs pendant la mise à jour du Launcher.
- Le processus de remplacement travaille maintenant depuis %LocalAppData%\RaidPilot Launcher\Updater, hors du dossier qu'il doit remplacer.
- En cas d'échec, le moteur restaure/rouvre une version fonctionnelle au lieu de laisser le Launcher fermé.
- Les opérations de self-update sont journalisées dans %LocalAppData%\RaidPilot Launcher\self-update.log pour permettre un diagnostic précis.
- Une migration unique peut être nécessaire pour les installations 0.2.3 à 0.2.7 qui possèdent encore l'ancien moteur de remplacement.

CORRECTIF ALERTE + VERSION AFFICHÉE 0.2.7
- Corrige le bouton INSTALLER LA MISE À JOUR qui pouvait continuer à clignoter alors qu'Overlay et Beacon étaient déjà à jour.
- Les suffixes Git comme 0.11.4+hash et 0.2.1+hash sont maintenant comparés comme leurs versions réelles 0.11.4 et 0.2.1.
- La version affichée en bas du menu n'est plus codée en dur : elle provient directement du Launcher réellement exécuté.
- Le clignotement disparaît immédiatement lorsque les trois composants sont réellement à jour.

CORRECTIF SELF-UPDATE 0.2.6
- Corrige le blocage où une build GitHub annonçait ProductVersion sous la forme 0.2.x+hash alors que le manifeste attendait 0.2.x.
- Le programme de mise à jour normalise maintenant les suffixes +commit/-metadata avant de comparer les versions.
- Les nouvelles builds Launcher n'ajoutent plus automatiquement le hash Git au ProductVersion Windows.
- Ce correctif permet aux Launcher 0.2.3/0.2.4/0.2.5 d'accepter correctement la prochaine mise à jour publiée.

SURVEILLANCE DES MISES À JOUR 0.2.5
- Tant que le Launcher reste ouvert, il vérifie automatiquement le canal Stable toutes les 2 minutes.
- La vérification se fait silencieusement en arrière-plan et ne désactive pas les boutons pendant le contrôle.
- Lorsqu'une nouvelle version d'Overlay, Beacon ou du Launcher est détectée, le bouton INSTALLER LA MISE À JOUR clignote jusqu'à l'installation.
- Le clignotement s'arrête automatiquement dès que tout est à jour ou pendant l'installation.
- Une panne réseau temporaire ne supprime pas une alerte de mise à jour déjà connue.
- Les mises à jour du Launcher lui-même sont maintenant incluses correctement dans le recalcul de disponibilité.

REDÉMARRAGE AUTOMATIQUE 0.2.4
- Après une mise à jour du Launcher lui-même, RaidPilot Launcher se ferme, installe la nouvelle version puis se rouvre automatiquement.
- Le redémarrage de la nouvelle version est vérifié pendant un court délai.
- Si la nouvelle version ne démarre pas correctement, la copie précédente est restaurée et le Launcher précédent tente de se rouvrir.
- Ce mécanisme évite qu'un utilisateur se retrouve sans Launcher après une mise à jour interrompue ou invalide.

ESCOUADE DIRECTEMENT DANS LE LAUNCHER 0.2.1
- Onglet Escouade intégré au launcher.
- Bouton CRÉER : génère immédiatement un code RP-XXXX-XXXX-XXXX-XXXX et le copie.
- Bouton COPIER : copie le code actuel pour l'envoyer aux teammates.
- Bouton REJOINDRE : entre le code d'une autre escouade et ton nom.
- Bouton NOM : modifie le nom visible par l'équipe.
- Boutons LANCER RAIDPILOT et LANCER BEACON directement dans la page Escouade.
- Le profil est écrit dans le même fichier que RaidPilot : le code est donc repris automatiquement au prochain lancement.
- Bouton QUITTER pour retirer le code du profil.

NOUVELLE INTERFACE 0.2.0
- Interface reconstruite pour reprendre le design approuvé : thème sombre tactique, accents cyan/bleu, grand hero RAIDPILOT, barre latérale et cartes d'état.
- Navigation : Accueil, Mise à jour, Jouer, Escouade, Paramètres, Notes de version et Aide.
- Version actuelle, dernière version, canal Stable et bouton LANCER RAIDPILOT regroupés dans le tableau principal.
- Cartes de fonctions : Carte interactive, Escouade, Guidage intelligent et Mises à jour.
- Historique visuel des dernières versions.
- Fenêtre sans bordure avec boutons minimiser/fermer et déplacement par la barre supérieure.
- Nouvelle identité visuelle RaidPilot conservée dans toute l'application.

INSTALLATION
Le launcher installe et lance RaidPilot Overlay et RaidPilot Beacon dans :
%LocalAppData%\RaidPilot Suite\Apps

MISES À JOUR
- Vérifie un manifeste JSON servi en HTTPS.
- Télécharge le ZIP de chaque composant.
- Vérifie son SHA-256 avant installation.
- Décompresse dans un dossier temporaire.
- Conserve la version précédente dans un dossier .previous.
- En cas d’échec de remplacement, restaure la version précédente.
- Les routes apprises, calibrations, préférences et profils d’escouade sont stockés hors du dossier de programme.

PREMIÈRE DISTRIBUTION
Le package du launcher contient une copie initiale de RaidPilot et Beacon dans payload\.

POUR ENVOYER DES MISES À JOUR
1. Héberge les ZIP RaidPilot et Beacon sur un serveur HTTPS, par exemple GitHub Releases.
2. Héberge update-manifest.json à une URL HTTPS stable.
3. Dans le launcher, ouvre Paramètres / Source des mises à jour et entre cette URL.
4. Les utilisateurs utilisent Mise à jour puis INSTALLER LA MISE À JOUR.

IMPORTANT
Les binaires restent non signés Authenticode. Une signature de code Windows reste recommandée pour limiter les avertissements SmartScreen.
